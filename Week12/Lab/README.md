### Generative AI Use:

Generative AI (Claude, Gemini) was used to assist me in completing the assignment. The tools were used primarily to help me better understand course concepts
and debug my code, such as the code for the CensoredNormalMLE class. I also use generative AI to help me write some code. The two places this was done was the
one hot encoding before creating the CensoredNormalMLE model (this was the result of my debugging earlier) and helping me write the code for getting the predictions 
for the censored model. I asked AI how it would recommend I do this tasks, looked at the options it gave me, and then implemented the one I thought seemed best into my code.
